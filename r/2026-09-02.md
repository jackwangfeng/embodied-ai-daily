# 2026-09-02 · 具身智能可参与项目日报

今日主线：**门槛已经掉到「一张消费级显卡 + 两千块硬件」这一档**。硬件侧被「3D 打印 + 舵机 + LeRobot 统一接口」拉平，模型侧被 450M 级 VLA 拉平 —— 这两件事在一年前分别属于机械工程实验室和 GPU 集群。国内的独特入口是**成体系的中文复现教程**（把「能不能做」变成「照着做」），国外的独特入口是**已经跑通并被引用的开源本体 + 模型权重**。

## 🇨🇳 国内

### ★ TOP 1（深度）· Datawhale `every-embodied` —— 从 0 手写 VLA 的中文工程路径

**类型：软件 ｜ 硬件成本 0 元（可纯仿真）｜ 周期 2–4 周（官方组队学习按 20 天排）**

**是什么。** Datawhale 社区维护的开源具身智能实战库，定位是「仅需 Python 基础，从 0 构建自己的具身智能机器人」。它的核心不是又一份 awesome 列表，而是**把 VLA 这条链路拆成能逐步手写的模块**：从最小可用的 VLA 骨架开始，逐层对照 OpenVLA / SmolVLA / π0 三个真实实现，最后落到能跑的抓取 demo。配套内容包括 MuJoCo 机械臂抓取基础 demo、LeRobot 遥操作（支持把 RDK-X5 接到 SO-101 机械臂）、以及在 Genie Sim / Isaac Sim 上部署 π0 的高保真仿真示例。同门项目 `dive-into-embodied-ai` 覆盖更偏决策侧的强化学习、World-Model 与运动规划，2026 年 7 月按「操作控制 / 感知建图 / 导航规划 / 世界模型」四条主线重排了 20 天路径。

**为什么现在值得做。** 具身智能这条链路的痛点从来不是缺论文，而是**缺一条已经被别人走通、且每一步都能验证的路**。个人自学最常见的死法是：看完 OpenVLA 论文，下载权重，跑不起来，卡在 CUDA / 数据格式 / 动作空间对不上，两周后放弃 —— 因为你无法判断是自己配错了还是本来就该这样。中文教程 + 逐步手写的价值正在于**每一步都有可对照的中间产物**，出错时能定位到具体哪一层。这类项目 2025 年基本不存在，2026 年才成熟起来。

**个人怎么切进去。**
1. **第一天（0 元，2 小时）**：clone 仓库，跑通 MuJoCo 抓取 demo。纯仿真，不需要任何硬件，这一步就能确认环境没问题。
2. **第一周（0 元）**：跟着手写最小 VLA —— 视觉编码器 + 语言条件 + 动作头，在仿真数据上过拟合到能动。**产出物是你自己写的、能跑的 VLA**，这是最有说服力的入门凭证。
3. **第二周（0 元）**：换成 SmolVLA / π0 的真实实现做对照，理解自己写的那版差在哪。
4. **第三周起（可选，约 ¥1700–2700）**：接真机（SO-101 或下面第 2 条的 reBot-DevArm），用 LeRobot 录自己的演示数据，微调、部署。

**坑 / 风险。** 三点要提前知道：① 社区教程的**更新节奏跟不上上游** —— LeRobot 主仓接口迭代很快，教程里的脚本可能对不上最新版，遇到报错先看仓库 issue 和 commit 日期，必要时锁定教程配套的 LeRobot 版本；② 仿真到真机有明确的鸿沟，**仿真跑通 ≠ 真机能抓**，别把仿真成功率当真机预期；③ 组队学习是周期性开的，错过了就只能自学，但材料本身一直在仓库里。

**出处。** [datawhalechina/every-embodied](https://github.com/datawhalechina/every-embodied)
相关：[dive-into-embodied-ai（决策与世界模型侧）](https://github.com/datawhalechina/dive-into-embodied-ai) ｜ [Embodied-AI-Guide（Lumina 社区技术指南，配套阅读）](https://github.com/TianxingChen/Embodied-AI-Guide) ｜ [LeRobotTutorial-CN（LeRobot 中文入门）](https://github.com/CSCSX/LeRobotTutorial-CN)

### 2 · Seeed reBot-DevArm —— 100% 全栈开源的开发用机械臂

**类型：硬件 ｜ 成本约 ¥1500–2500 ｜ 周期 2–3 周（含到货与装配）**

- **是什么 / 为什么。** 明确以「降低具身智能学习门槛」为目标的机械臂项目，2026 年 5 月 11 日转为 **CERN-OHL-W 2.0** 许可，硬件与软件双侧 100% 开源 —— 这在国产机械臂里少见，多数是「软件开源、图纸不给」。国内供应链买件和售后是实打实的优势，不用等跨境物流。
- **怎么切进去。** 直接买套件（比自己打印省事，精度也更稳），装完接 LeRobot 的录制脚本采数据。第一个可交付产出：**50 组抓取演示 + 一个能复现抓取的 policy**，数据集可以直接传 Hugging Face。
- **坑。** 舵机型号和固件版本要和文档严格对上，替换件容易在通信协议上踩坑；开源许可 CERN-OHL-W 是「弱互惠」，改了硬件设计再分发需要同样开源。
- **出处。** [Seeed-Projects/reBot-DevArm](https://github.com/Seeed-Projects/reBot-DevArm)

### 3 · 智元灵犀 X1 —— 人形机器人「0 元购」全套图纸 + RL 训练代码

**类型：软硬件全套 ｜ 个人参与成本 0 元（只用仿真侧）｜ 周期 1–2 周**

- **是什么 / 为什么。** 智元把模块化高自由度人形机器人 X1 整套开源：整机结构图纸、硬件框图、细到螺丝齿轮的 BOM，以及 AimRT 中间件组件、URDF、Sim2Sim / Sim2Real 代码、强化学习训练代码、模型转换与调试工具。**整机对个人显然不是「投入可控」，但仿真 + RL 训练那一半是完全免费的** —— 这是个人少有的、能拿到工业级人形机器人完整 RL 训练管线的机会。
- **怎么切进去。** 只碰 `agibot_x1_train`：在仿真里训一个行走策略，跑 Sim2Sim 验证迁移，用他们的可视化工具看训练曲线。**产出物是一条自己训出来的人形步态策略**，纯软件、纯显卡时间。想更进一步再看硬件仓的 BOM 评估局部复现（比如只做一条腿）。
- **坑。** RL 训练对显存和时间敏感，参数没调好会长时间不收敛，先按官方给的默认配置跑通再改；`Sim2Real` 那部分没有真机就无法验证，别把它当成「已经会了」。

## 🌍 国外

### ★ TOP 1（深度）· SmolVLA —— 450M 参数的 VLA，单卡就能全量微调

**类型：软件 ｜ 硬件成本 0 元（有显卡即可）｜ 周期 1–2 天出结果**

**是什么。** Hugging Face 发布的视觉-语言-动作模型，建立在 SmolVLM 之上，加了一个 diffusion 动作头，从图像观测 + 语言指令直接输出机器人关节指令。**450M 参数，比前沿机器人模型（5–7B）小一个数量级。**

**为什么现在值得做。** 这是整条链路上**唯一被真正打穿的瓶颈**。此前个人做 VLA 的现实是：OpenVLA 级模型微调要多卡 A100，等于把门槛设在「有实验室或愿意烧租金」。SmolVLA 把数字改成了：**单张 RTX 4090（24 GB）可全量微调，200 组演示 4–12 小时**；有人在笔记本 RTX 3050 Ti 加免费 Colab 上做完了微调。INT8 量化后权重约 2.5 GB，8 GB 显存能推理。代价是精度让了一点 —— LIBERO benchmark 上 82–90%，和 OpenVLA 差 5% 以内，对比 π0 是 78% vs 85%。**用 7% 的精度换掉 16 倍的参数量和整个 GPU 集群，对个人来说这个交易毫无悬念。**

**个人怎么切进去。** 这条**今天就能开工，完全不用等硬件到货**，也是六条里唯一当天能看到进展的：
1. **今天（2 小时）**：拉 LeRobot 上现成的公开数据集，按官方微调脚本跑一次，把「数据加载 → 训练 → 评估」这条流程走通。先不求效果，只求不报错。
2. **明天（4–12 小时显卡时间）**：换一个具体任务的 200 组演示做全量微调，记下 benchmark 前后差值。**产出物是一个你自己微调的 VLA checkpoint + 一条可复现的训练配置**，可以直接传 HF。
3. **硬件到货后**：把公开数据集换成自己录的真机数据，同一套流程不用改。
4. **本机备注**：这台机器就是 RTX A4000 16G（驱动 590.48 / CUDA 13.1，`. /workspace/cuda/env.sh` 已配好）—— 16 GB 做全量微调偏紧，可以用 LoRA 或减小 batch，推理绰绰有余。要我直接开跑就说一声。

**坑 / 风险。** ① **benchmark 分数不是你的场景分数** —— 换到新环境掉点比论文里狠得多，per-task 微调基本是必须的，别拿 82–90% 当自己的预期；② 4090 的 24 GB 是官方给的全量微调门槛，**16 GB 以下要走 LoRA / 梯度检查点**，直接跑会 OOM；③ 演示数据的质量比数量重要得多，200 组抖动混乱的遥操作数据不如 50 组干净的。

**出处。** [SmolVLA 官方博客](https://huggingface.co/blog/smolvla)
相关：[论文 arXiv:2506.01844](https://arxiv.org/abs/2506.01844) ｜ [微调实操教程（含完整代码）](https://medium.com/correll-lab/fine-tuning-smolvla-for-new-environments-code-included-af266c56d632) ｜ [LeRobot 主仓](https://github.com/huggingface/lerobot)

### 2 · AM-ARM200 —— $240 的 6+1 DoF 开源机械臂，LeRobot 开箱即用

**类型：硬件 ｜ 成本 $240 单臂 / $380 全套遥操作套件（约 ¥1700 / ¥2700）｜ 周期 2–3 周**

- **是什么 / 为什么。** 全 3D 打印、6+1 自由度、1 kg 负载，**开箱即与 LeRobot 对接** —— SO-101 那套录制和训练脚本直接能用，省掉最烦的驱动适配。follower $240 / leader $140 / 全套 $380。它的意义是把「遥操作采数据」这件事的成本压到了个人可承受区间，而采数据是所有模仿学习的前提。

- **坑。** FDM 打印件的层高与舵机间隙直接吃掉重复定位精度，别指望亚毫米；跨境到货周期要算进计划。

## 趋势观察

1. **国内外的分工正在清晰。** 国外产出「被引用的开源本体和模型权重」（LeRobot 生态、SmolVLA、LEAP Hand），国内产出「成体系的复现路径和供应链」（Datawhale 教程、Seeed 套件、智元全套图纸）。对个人最优的组合是**用国外的模型和框架，走国内的教程和供应链**。
2. **硬件形态在收敛。** 「3D 打印结构件 + 串行总线舵机 + LeRobot 接口」几乎成了默认答案，AhaRobot 把双臂移动操作机做到 $1000 / 0.7 mm 重复定位 —— 一年前这是实验室价位。形态收敛意味着**换本体不用重写软件栈**，个人的时间投入终于可以积累了。
3. **瓶颈从「算力」移到了「数据」。** 模型能单卡微调之后，卡人的变成了「你有没有一批干净的真机演示数据」。这也解释了为什么低成本遥操作套件（leader-follower）比机械臂本身更值得先买。
4. **参与入口（比赛）本期空缺。** 已知的国内赛事时间点都偏早：[高通具身智能与机器人开发者大赛](https://tech.china.com/articles/20260508/202605081862979.html) 5 月启动、第二届无人系统具身智能算法挑战赛报名 7 月 15 日截止、清华-西门子工业具身智能挑战赛（9.4 万奖金）也已开赛。**均未核实到当前仍开放的报名入口，故不列为可参与项**，后续每期会专门核一遍截止日期。
