★ TOP 1（深度）· Datawhale every-embodied —— 从 0 手写 VLA 的中文工程路径

类型：软件 ｜ 硬件成本 0 元（可纯仿真）｜ 周期 2–4 周（官方组队学习按 20 天排）

是什么。 Datawhale 社区维护的开源具身智能实战库，定位是「仅需 Python 基础，从 0 构建自己的具身智能机器人」。它的核心不是又一份 awesome 列表，而是把 VLA 这条链路拆成能逐步手写的模块：从最小可用的 VLA 骨架开始，逐层对照 OpenVLA / SmolVLA / π0 三个真实实现，最后落到能跑的抓取 demo。配套内容包括 MuJoCo 机械臂抓取基础 demo、LeRobot 遥操作（支持把 RDK-X5 接到 SO-101 机械臂）、以及在 Genie Sim / Isaac Sim 上部署 π0 的高保真仿真示例。同门项目 dive-into-embodied-ai 覆盖更偏决策侧的强化学习、World-Model 与运动规划，2026 年 7 月按「操作控制 / 感知建图 / 导航规划 / 世界模型」四条主线重排了 20 天路径。

为什么现在值得做。 具身智能这条链路的痛点从来不是缺论文，而是缺一条已经被别人走通、且每一步都能验证的路。个人自学最常见的死法是：看完 OpenVLA 论文，下载权重，跑不起来，卡在 CUDA / 数据格式 / 动作空间对不上，两周后放弃 —— 因为你无法判断是自己配错了还是本来就该这样。中文教程 + 逐步手写的价值正在于每一步都有可对照的中间产物，出错时能定位到具体哪一层。这类项目 2025 年基本不存在，2026 年才成熟起来。

个人怎么切进去。

  1. 第一天（0 元，2 小时）：clone 仓库，跑通 MuJoCo 抓取 demo。纯仿真，不需要任何硬件，这一步就能确认环境没问题。
  2. 第一周（0 元）：跟着手写最小 VLA —— 视觉编码器 + 语言条件 + 动作头，在仿真数据上过拟合到能动。产出物是你自己写的、能跑的 VLA，这是最有说服力的入门凭证。
  3. 第二周（0 元）：换成 SmolVLA / π0 的真实实现做对照，理解自己写的那版差在哪。
  4. 第三周起（可选，约 ¥1700–2700）：接真机（SO-101 或下面第 2 条的 reBot-DevArm），用 LeRobot 录自己的演示数据，微调、部署。

坑 / 风险。 三点要提前知道：① 社区教程的更新节奏跟不上上游 —— LeRobot 主仓接口迭代很快，教程里的脚本可能对不上最新版，遇到报错先看仓库 issue 和 commit 日期，必要时锁定教程配套的 LeRobot 版本；② 仿真到真机有明确的鸿沟，仿真跑通 ≠ 真机能抓，别把仿真成功率当真机预期；③ 组队学习是周期性开的，错过了就只能自学，但材料本身一直在仓库里。

★ TOP 1（深度）· SmolVLA —— 450M 参数的 VLA，单卡就能全量微调

类型：软件 ｜ 硬件成本 0 元（有显卡即可）｜ 周期 1–2 天出结果

是什么。 Hugging Face 发布的视觉-语言-动作模型，建立在 SmolVLM 之上，加了一个 diffusion 动作头，从图像观测 + 语言指令直接输出机器人关节指令。450M 参数，比前沿机器人模型（5–7B）小一个数量级。

为什么现在值得做。 这是整条链路上唯一被真正打穿的瓶颈。此前个人做 VLA 的现实是：OpenVLA 级模型微调要多卡 A100，等于把门槛设在「有实验室或愿意烧租金」。SmolVLA 把数字改成了：单张 RTX 4090（24 GB）可全量微调，200 组演示 4–12 小时；有人在笔记本 RTX 3050 Ti 加免费 Colab 上做完了微调。INT8 量化后权重约 2.5 GB，8 GB 显存能推理。代价是精度让了一点 —— LIBERO benchmark 上 82–90%，和 OpenVLA 差 5% 以内，对比 π0 是 78% vs 85%。用 7% 的精度换掉 16 倍的参数量和整个 GPU 集群，对个人来说这个交易毫无悬念。

个人怎么切进去。 这条今天就能开工，完全不用等硬件到货，也是六条里唯一当天能看到进展的：

  1. 今天（2 小时）：拉 LeRobot 上现成的公开数据集，按官方微调脚本跑一次，把「数据加载 → 训练 → 评估」这条流程走通。先不求效果，只求不报错。
  2. 明天（4–12 小时显卡时间）：换一个具体任务的 200 组演示做全量微调，记下 benchmark 前后差值。产出物是一个你自己微调的 VLA checkpoint + 一条可复现的训练配置，可以直接传 HF。
  3. 硬件到货后：把公开数据集换成自己录的真机数据，同一套流程不用改。
  4. 本机备注：这台机器就是 RTX A4000 16G（驱动 590.48 / CUDA 13.1，. /workspace/cuda/env.sh 已配好）—— 16 GB 做全量微调偏紧，可以用 LoRA 或减小 batch，推理绰绰有余。要我直接开跑就说一声。

坑 / 风险。 ① benchmark 分数不是你的场景分数 —— 换到新环境掉点比论文里狠得多，per-task 微调基本是必须的，别拿 82–90% 当自己的预期；② 4090 的 24 GB 是官方给的全量微调门槛，16 GB 以下要走 LoRA / 梯度检查点，直接跑会 OOM；③ 演示数据的质量比数量重要得多，200 组抖动混乱的遥操作数据不如 50 组干净的。
