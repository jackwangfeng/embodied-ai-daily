2026-09-06 · 具身智能可参与项目日报

今日主线：这一周具身智能圈只有一件事 —— 机器鸭。 Hugging Face / Pollen Robotics 的 $399 开源双足 Microduck 8 月 27 日开订，24 小时约 6500 台、$260 万，被普遍称作具身智能的「树莓派时刻」。它真正改变的不是价格（个人复刻一台反而要 ¥4100–5800），而是把「SDK + 仿真 + RL 训练栈」整条链路以 Apache-2.0 一次性给全了，并且顺带把一个此前被含糊带过的问题摆到台面上：开源硬件的「源」到底开到哪一层。国内开发者在开订次日就开始从官方仿真模型反推装配图，本期国内 top1 就是这条反推工程链。模型与仿真侧同期两件事：小米 XR-1 全量开源（README 明写「面向消费级显卡优化」），Meta 开源专为接触做的灵巧操作仿真平台 SuperDex。

🇨🇳 国内

★ TOP 1（深度）· microduck-replica —— 从仿真模型反推出整机工程的中文复刻仓

类型：硬件（逆向工程 / CAD / 电控）｜纸面阅读 0 元，真做一台约 ¥4100–5800 ｜周期：读通 1–2 天，动手 3–6 周

是什么。 Microduck 开订第二天（2026-08-28）建仓，477 ⭐，9 月 1 日打了 v1.0，9 月 5 日仍在更新。它做的事是：从官方公开的 MJCF 仿真模型 + 47 个 STL 网格，反推出机械复刻所需的全部信息 —— 装配爆炸图（15 个部件沿运动链炸开、标注质量）、可直接导入 CAD 的装配体（世界变换已应用）、38 种网格 / 75 个实例的整机 BOM、约 325 件 M2 紧固件清单、轴承规格（Ø22×16×4、Ø15×10×3）、14 个受控关节的轴线与行程、15 个刚体的质量惯量。电控侧从 Rust 源码完整还原，并且把官方唯一没有开源的 imu_to_dxl 板画了出来（STM32G031F8P6 + LSM6DSV16X + 半双工缓冲，作为第 16 个设备挂在舵机总线上），附嘉立创工程和接线表。另有一份构建日志记录真实打印与装配过程。

为什么现在值得做。 三个理由，都不是「因为鸭子火」：

其一，这是一次可以完整旁观的「从仿真资产反推实体工程」。MJCF 里藏着精确到 0.1 mm 的运动学树、每个零件挂在谁身上、绕哪根轴转、行程多少、质量和惯量张量 —— 把这些还原成装配关系是一门通用手艺，换任何一个「只放了仿真资产、不给 CAD」的机器人项目都能用。而这类项目正在变多。

其二，这个仓库的工程记录质量高于结论本身。它把「哪些是纸上反推、哪些是实物验证、哪些还没验证」逐条标出来，甚至在 README 顶部公开挂了自己的勘误：9 月 3 日承认此前写的「硬件不开源、没有 PCB 原理图」是错的 —— 原因是只检索了 microduck 主仓，漏查了同组织下 elec_ 前缀的硬件仓库。愿意这样自曝错误的开源工程日志，值得当范本读。

其三，它有接收方。仓库正在公开求原理图评审，200 人的微信一群已满、二群在开。不是一个人的自嗨。

个人怎么切进去。

  1. 今天（0 元，2 小时）：读 BOM.md + 装配爆炸图 + docs/紧固件反推.md，先判断自己到底要不要做。BOM 里每一项都标了依据和核对日期，可以直接当决策材料。
  2. 本周（0 元，纯软件）：clone pollen-robotics/microduck_rl，在 MuJoCo 里把官方策略跑起来、再自己训一条。软件侧是 Apache-2.0 全开的，这一半和你有没有硬件完全无关，本机 A4000 训 PPO 走路策略绰绰有余。这是本期六条里唯一今天就能看到进展的动手项。
  3. 想真做（¥4100–5800，3–6 周）：按仓库的 docs/电控采购清单.md（带淘宝实链）买件 → 打印 47 个件 → HAT 板直接拿官方 KiCad 工程打样（4 层板，不用自己画）→ imu_to_dxl 用本仓库的第三方原理图打样。
  4. 最有性价比的贡献路径（0 元）：仓库明确点名想听三处意见 —— 半双工缓冲的使能逻辑（2OE 接常高、发送时有回显，还是也接 DE、发送时 RX 悬空）、J1/J2 直通的铜皮宽度、不上晶振时 HSI16 跑 1 Mbps 的余量够不够。有硬件背景的话，开一个 issue 就是实打实的贡献，成本为零。

坑 / 风险。 五条，第一条最重要：

① 复刻不省钱，反而更贵。 15 个 Dynamixel XL330 光舵机就 $359（ROBOTIS 国际站 $23.90/个）到 $412（美国站 $27.49/个），欧洲含税要 €603–629；加上主控与传感器（$80–120）、电池供电（$30–50）、轴承（$15–30）、紧固件（$15–25）、两块 PCB 打样含 SMT（$60–150）、打印耗材（$15–30），总额约 $575–815 ≈ ¥4100–5800，比 $399 的原版还贵。$399 是矽递规模化量产 + 官方供应链的价格，个人复刻不可能达到。做这件事的理由是「能立刻动手 + 学到反推手艺 + 可以换国产平替舵机降本」，不是省钱。

② 仿真 STL 不是可打印工程件。 仓库自己反复强调这句，构建日志就是在验证它。目前首批打印件（头壳、躯干壳、腿部结构件、脚）已出、腿部件的 M2 紧固件反推在实物上成立，但整机还没装完。

③ imu_to_dxl 原理图没打样、没实物验证，连通性只逐网络核对过（无悬空脚、无短路），已按社区评审补了 DE 与 DXL_DATA 两处上拉。要打样自己承担风险。

④ 走线方案官方零资料，仓库标为「❌ 缺失」。

⑤ 官方给 XL330 超压运行 —— 额定 3.7–6.0 V，Microduck 实际给 6.6–8.2 V（HAT 上 Dynamixel 接口直接接电池原电压，板上唯一的 5 V 降压是给树莓派的）。这是官方的选择不是笔误，但复刻时要知道它吃舵机寿命。

2 · 小米 Xiaomi-Robotics-1（XR-1）—— 10 万小时数据训出来的 VLA，官方写明「面向消费级显卡优化」

类型：软件 ｜硬件成本 0 元（有显卡即可）｜周期 2–5 天

  • 是什么 / 为什么。 小米机器人团队 8 月初放出的完整开源套件（Apache-2.0）：后训练、推理、benchmark 评测代码 + 各 benchmark 的微调 checkpoint，基础模型 XR-1-5B 在 HF。架构是 Qwen3-VL 通过 Mixture-of-Transformers 耦合一个 Diffusion Transformer 动作头；训练走「10 万+ 小时无本体 UMI 轨迹预训练 → 1 万+ 小时跨本体后训练」两段式。截至 2026-07-15 在 RoboCasa365 和 RoboDojo 两个榜单都排第一。README 明确写「built on HF transformers（pin 到 4.57.1）and optimized for consumer GPUs」—— 这句话是它区别于多数国产大模型开源的地方。

★ TOP 1（深度）· Project SuperDex —— Meta 开源的接触优先物理引擎，pip 装得上

类型：软件 ｜硬件成本 0 元 ｜周期 1 天跑通，1–2 周出策略

是什么。 Meta（facebookresearch）2026-08-20 开源、Apache-2.0、589 ⭐、9 月 5 日仍在推进的灵巧操作统一仿真平台。四个部件：SuperDex Physics（为触觉操作专门做的 contact-first 物理引擎，是整个项目的仿真骨干）、SuperDex Robotics（机器人定义、控制器、传感器、执行器的 SDK）、SuperDex Studio（把 CAD 和机器人描述转成原生资产的桌面 GUI）、SuperDex Lab（Gymnasium 风格的 RL 接口，early preview）。

为什么现在值得做。 灵巧操作这条线的瓶颈很具体：接触仿真的保真度。多指抓取、柔性指尖、绳索编织、拧螺纹这类任务，通用引擎一直吃力，而这恰好是灵巧手研究的全部内容。SuperDex 是第一个由大厂以 Apache-2.0 放出、且专门为接触做的引擎。更关键的是交付方式：uv pip install superdex 装预编译 wheel，不用编译 C++、不用配 CUDA。对比一下 —— 上期我们说模型侧的门槛被 SmolVLA 打穿了，这一条是仿真侧的同一件事。

个人怎么切进去。

  1. 今天（1 小时）：装 uv → uv venv → uv pip install superdex → 跑两个官方例子：superdex_physics/examples/example_tendon_comparison.py（腱驱对比）和 superdex_robotics/examples/control/example_osc_jsc_control.py（控制）。注意仓库内 uv run 必须加 --no-project，否则它会从源码构建。
  2. 本周：用 SuperDex Studio 把一个已有的开源手 URDF（LEAP Hand、AmazingHand 都行）导成 SuperDex 资产，产出物是一份可复用的资产文件。
  3. 第二周：用 Lab 的 Gym 接口在一个抓取 / 拧转任务上训 PPO。产出物是一条策略 + 一份「同一任务在 SuperDex 与 MuJoCo 下接触表现的对比记录」 —— 后者是目前社区里几乎没人做过、又很容易被引用的东西。
  4. 本机备注：A4000 16 G 跑 RL 够用；但下面第 3 条坑要先看。

坑 / 风险。 ① SuperDex Lab 是 early preview，官方明说会有实质改动，别把接口写死进你的项目；② SuperDex Teleop（Quest 3 上的 VR 遥操作）要 Q4 2026 才有，画廊里那些实时遥操作视频现在复现不了，别按它规划；③ 只提供 Python 3.12 的 wheel，更灵活的 abi3 wheel 是「future release」；④ Linux 上 Studio 和 Physics Debugger 需要 X11/XWayland + OpenGL 4.1 驱动，无头容器里 GUI 起不来，只能跑 headless 的物理与 RL 部分。
