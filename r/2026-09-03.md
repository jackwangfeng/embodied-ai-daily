### ★ TOP 1（深度）· Wall-OSS-0.5 / WALL-X —— 国产 4B VLA，官方给了单张消费级卡的部署脚本

**类型：软件 ｜ 硬件成本 0 元（有显卡即可）｜ 周期 当天见结果，1 周出基线**

**是什么。** 自变量机器人（X Square Robot）开源的具身基础模型，口号是 *Pretrain Once, Act Anywhere*。**4B 参数**（3B 视觉-语言主干 + 动作生成部件），在 20 多种本体形态上预训练、每 epoch 处理百万级机器人轨迹，用「梯度桥接」共训练把离散动作预测、多模态预测和连续 flow matching 缝在一起。官方数字：预训练 checkpoint **不做任务微调**直接零样本测 17 个任务，4 个上 80 分（满分 100）；微调后 15 个任务平均进度 60.5，比 π0.5 高 17.5。权重、代码、技术报告都公开。

**为什么现在值得做。** 模型是 5 月放出来的，但**这周（8 月 31 日）仓库里落的两样东西才让它从「论文 + 权重」变成「能照着跑」**：

1. **`workspace/rtx5090/`** —— 官方写的单张消费级显卡推理部署路径：`install.sh` 装环境、`run_server.sh` 起推理服务、`DEPLOY.md` 是不绑本机的通用流程、还给了 `curl http://127.0.0.1:44660/healthz` 的健康检查和 `ENABLE_CUDA_GRAPH=1` 这类实测过的环境变量，外加一份 `local/NOTES.md` 记录踩坑。国产具身大模型里，官方主动写「怎么在一张民用卡上把服务起起来」的还不多。
2. **`workspace/TRAIN_ARRANGE_3_FLOWERS.md`** —— 一份**配方级**的微调指南。双臂三花插花任务，把 26 维动作空间怎么对齐写得很死：左右臂各「相对位姿 3 + 6 + 夹爪 1 = 10 维」，有效动作 20 维，剩下 6 维用 `action_padding` 补齐到预训练空间的 26 维且 **loss 不反传**；三视角 448×448、建议 20 fps。配套还加了 `x2robot2lerobot.py` 数据格式转换脚本和 smoke 配置。这类「动作空间怎么对齐」的文档，恰恰是个人复现 VLA 时最容易卡死、又最没人写的一层。

**个人怎么切进去。**

1. **今天（2 小时，0 元）**：clone 仓库，从 HF 拉 `wall-oss-0.5` 权重，跑 `python scripts/fake_inference.py --checkpoint-path <ckpt>` —— 最小端到端例子，只确认环境和权重对得上。4B 在 bf16 下推理约 8–9 GB 显存，本机 A4000 16G 够用（`. /workspace/cuda/env.sh` 已配好）。
2. **第 1–2 天（0 元）**：`bash scripts/run_libero.sh <ckpt>` 跑 LIBERO 闭环仿真评测，拿一组**自己机器上的基线分数**。纯仿真、可复现，这是第一个真实产出物。
3. **第 3–5 天（0 元）**：起 WebSocket 推理服务（`scripts/run_serving.sh`），用开环评测把模型预测动作和公开 LeRobot 数据集里的真值对比，`scripts/draw_openloop_plot.py` 直接出图。**产出物是一份开环误差曲线**，比一个分数更能说明模型在你关心的任务上差在哪。
4. **第 2 周起（可选）**：照 `TRAIN_ARRANGE_3_FLOWERS.md` 那套动作空间对齐方法，把自己的 LeRobot v3 数据集接上做微调。

**坑 / 风险。** 四点，前两点会直接卡住你：

① **LeRobot 版本被锁在 v0.4.4**，不是当前最新的 0.6.1 —— 装最新版会对不上，官方安装步骤专门交代对 lerobot 用 `--no-deps` 以免覆盖 wall-x 的依赖。这是「教程跟不上上游」的反面：这里是**上游跑太快，配方锁在旧版**。
② **训练入口是 `wall_x.trainer.fsdp_trainer.train_fsdp`（FSDP，多卡取向）**。4B 全量微调不是单张 16 GB 卡的活，按官方配置直接开会 OOM，单卡只能走 LoRA / 极小 batch + 梯度检查点。**推理和评测在 16G 上没问题，微调要降级预期。**
③ 需要 flash-attn（训练与推理的 vision 模块都要），编译经常是整个流程里最大的时间黑洞，先解决它再谈别的。
④ 那份插花配方是给双臂 ex001 本体的。**你没有同构本体时，动作空间映射要自己重做**，这一步的工作量比文档看起来大得多 —— 别把「有配方」理解成「换个数据集就能跑」。

**类型：硬件 ｜ 成本 单臂约 ¥5.3k、主从一对约 ¥1.05 万（⚠️ 超出本栏目「≤ 约 5000 元」口径，见下）｜ 周期 2–3 周**

- **是什么 / 为什么。** 宇树科技自己设计并开源的 6-DoF 机械臂，8 月 28 日更新。硬件目录给全了：采购清单（带单价和链接）、STEP、STL、装配指导、电机配置方法；软件侧支持 **VR 手柄 / 键盘 / 主从臂三种控制模式**，固定频率录制关节角与相机图像，输出标准格式数据集，直接对接 [unitree_lerobot](https://github.com/unitreerobotics/unitree_lerobot) 做模仿学习训练与部署。整条链是 `硬件准备 → 校准 → 配环境 → 遥操作采数 → 训练 → 部署`。
- **成本要说实话。** 按仓库自带清单算：**J288 舵机 ¥599 × 8 = ¥4792/臂**，加电机控制板 ¥99、腕部相机 ¥190、全局相机 ¥183、线材电源固定件约 ¥100 —— **单条从臂约 ¥5.3k**；官方推荐的主从遥操作要买两套（16 颗舵机），**约 ¥1.05 万**。这条**确实超了本栏目 5000 元的口径**，之所以还列进来：它是本周唯一一个由头部厂商官方开源、软硬件文档都齐的国产机械臂，且有下面这个省钱切法。

- **坑。** ① 成本主体就是舵机，**别指望换廉价舵机省钱** —— 通信协议、减速比、力矩全都对不上，会毁掉整条软件链的开箱可用性；② 仓库许可是 `NOASSERTION`（没给标准 SPDX 许可标识），个人研究无碍，**商用前必须找官方确认**；③ 采购链接是淘宝/天猫短链，会失效，失效了按型号（J288）自行搜。

### ★ TOP 1（深度）· quackd —— 给小机器人接一个 LLM 大脑，零硬件零 API key 当天能跑

**类型：软件 ｜ 硬件成本 0 元 ｜ 周期 10 分钟起步，1 周出可提交的贡献**

**是什么。** 8 月 28 日才建仓的开源项目（Apache-2.0，PyPI 有包，**两周 120★**），定位是「小机器人缺的那层大脑守护进程」—— 名字和 `robotd` / `mediad` 这些兄弟守护进程对齐。它**不训练端到端 VLA**，而是让一个 LLM（Claude / OpenAI / Gemini / Grok，或用 Ollama、vLLM、llama.cpp、LM Studio 跑本地模型）**调度机器人已经会的技能**：把 *"find the ball and kick it"* 这样一句话变成一串它自己的 skill 调用，观察发生了什么，继续循环，直到完成或明确判定不可能。任务写在 `.duck` 文件里，自带模拟器，**支持 MCP**（可以直接在 Claude 里对话驱动），还有 flock 模式让不同形态的机器人协作（「头负责发现，鸭子负责踢，头负责判定」）。首个目标机型是 Pollen Robotics 的 Microduck 双足，0.4 起通过 adapter 也驱动 Reachy Mini 头、SO-101 级机械臂（走 LeRobot）和任意 rosbridge 轮式底盘。

**为什么现在值得做。** 三点，第三点是关键：

① **门槛是本期最低的**：`uvx quackd run find-and-kick --provider fake` —— 不需要机器人、不需要显卡、不需要 API key，自带模拟器在任何笔记本上几秒起来。
② **技术路线是 VLA 之外的另一条路**。VLA 那条线要数据、要显卡、要本体，个人的第一个可展示成果通常在两三周后。这条线假设机器人已经会 walk / turn / kick / scoop / look around 这些技能，**LLM 只做任务分解和闭环监督** —— 代价是能力天花板受限于机器人已有的技能集，好处是**今天就有能演示的东西**。
③ **它的空白处就是贡献入口，而且作者把清单列在 README 里了。** 这个仓库诚实到罕见：明确写了「四个硬件后端全是 experimental 或 stub，**没有任何一个在真机上端到端验证过**」；`hello-world` 和 `find-and-kick` 已被 scripted pilot 跑通（10/10 seeds + ground truth 检查），但 **`patrol-and-quack` / `follow-me` / `fetch` 这三个任务至今没有任何 pilot 跑通过**（scripted pilot 对 follow-me 和 fetch 根本没有脚本，跑两步就宣称成功；patrol 每个 seed 都跑到预算耗尽；模型运行则一次记录都没有）。**一个两周龄、120★、Apache-2.0 的项目，把自己没做完的事逐条列出来 —— 这是最容易变成 merged PR 的形态。**

**个人怎么切进去。** 这条是六条里唯一「十分钟内能看到东西动」的：

1. **今天（10 分钟，0 元）**：`uvx quackd run find-and-kick --provider fake`，看 scripted pilot 在自带模拟器里找到球并踢出去。确认环境没问题。
2. **今天（1 小时，0 元）**：`claude mcp add quackd -- uvx quackd serve-mcp --robot microduck:sim2d`，然后直接用自然语言驱动它。**本机就是 Claude Code 环境，这一步没有额外成本** —— 要我直接接上跑就说一声。
3. **本周（0 元 / 少量 token）**：换成真模型去跑 `follow-me` 或 `fetch`。**README 明确说这两个还没有任何模型跑通记录** —— 跑通并提交一份 run 记录，就是一条实打实的首次贡献。想完全免费就用 Ollama 跑本地模型。
4. **进阶（有硬件的话）**：写一个 adapter。SO-101 级机械臂的后端目前**只有 mock**，你手上有 SO-101 / SO-ARM101 的话，把它接到真机是这个项目现在最缺的东西 —— 也是把昨天那批便宜机械臂（AM-ARM200、reBot-DevArm）用起来的一个新去处。

**坑 / 风险。** ① **它现在诚实的标签是「LLM 驱动的、目标导向的仿真机器人控制」**，不是能用的实体机器人大脑。别按「买个 Microduck 就能用」来规划 —— **Microduck 硬件要 2026 圣诞才发货**；② 任务分解依赖 LLM，云模型有 token 成本，本地模型（Ollama / llama.cpp）效果会明显掉一档，`follow-me` 这类多步任务尤其明显；③ 两周龄项目，接口还在动（0.4 才加的多机型 adapter），**锁版本再动手**，别在 main 上建工作流。

### 2 · HFlow —— 查「你那批演示数据到底能不能用」的开源 SDK

**类型：软件 ｜ 成本 0 元 ｜ 周期 1–2 天**

- **是什么 / 为什么。** Hebbian Robotics（YC S26）8 月 18 日开源的多模态机器人数据流水线 SDK，Apache-2.0，**两周 228★**。它解决的问题非常具体：一批语料里混着来自不同录制系统的视频、状态、动作、时间戳和元数据，你怎么知道**相机有没有卡帧、多路流有没有失同步、必需的 topic 有没有消失、有没有重复录制混进来**。HFlow 给每个处理过的 episode 打 provenance 戳、把流水线渲染成图、把元数据和质量证据写进可查询的目录 —— **不加载原始录像就能审计整个语料库**。**这条直接接上昨天的判断（瓶颈从算力移到数据）**：个人做模仿学习最隐蔽的失败模式是「数据脏了但你不知道」—— 训练 loss 好看，真机不动，然后你去调超参，方向就彻底错了。
- **怎么切进去。** 拿 HF 上任意公开 LeRobot 数据集跑内建 checks → **产出物是一份 QC 报告**（哪些 episode 该扔、为什么）；进一步写一个自己的 check（比如夹爪状态跳变、动作值越界检测）提 PR。0 元、0 硬件、一两天，而且这份报告在你后面真机采数据时会一直有用。
- **坑。** ① 是**公司主导**的开源项目（YC S26），路线图跟着商业产品走，别当社区中立基建来押长期；② 它**管数据不管模型** —— 别指望它提升 policy 效果，它只让你知道数据有没有问题，价值在「省掉一周走错方向」；③ 内建 checks 是通用的，你的具体任务（比如力控、触觉）要自己写 check 才有意义。

### 3 · LeRobot Humanoid —— HF 官方的 < $5000 开源人形，8/27 五个子仓同日更新

**类型：硬件 ｜ 成本 分层：0 元 / 几百元 / $5000（见下）｜ 周期 0 元层 1 周**

- **是什么 / 为什么。** Hugging Face 官方的开源低成本人形机器人工作区，**8 月 27 日 design / hardware / model / runtime / identification 五个子仓同日更新**。目标写得很明确：整机 **< $5000**、优先减重与可维护、**3D 打印优先**（多数自制机械件可打印且有文档）、从 CAD 到运行时全链可复现。hardware 仓里有**公开的 Onshape CAD 源**、机读 + 人读双份 BOM、按左右腿和子装配拆好的 STL（`hipx` / `hipz` / `thigh` / `knee_mechanism` / `shin` / `ankle_mechanism` / `ankle` / `foot`）、接线与连接器映射、电机预装配调试工具。当前范围只做双足平台，上半身暂不在内。
- **怎么切进去（成本分层，别只看 $5000）。**
  - **0 元层（推荐先做这个）**：`lerobot-humanoid-identification` 是**纯仿真** —— MJWarp 批量回放 + CMA-ES 辨识仿真参数，README 明确写「真机采集 / 延迟工具**刻意不在本仓范围内**」。也就是说这一半**完全不需要任何硬件**，一张显卡就能做，产出物是一组辨识出来的仿真参数 + 运行产物。这是本机 A4000 现在就能开工的活。
  - **几百元层**：STL 已经按子装配拆好了，**可以只打印并复现一个关节模块**（比如 `knee_mechanism` 或 `ankle_mechanism`），验证打印件公差和电机预装配流程，成本是几百元的打印件加一两颗电机。
  - **$5000 层**：完整双足平台。**超出本栏目预算，作为长期目标看，不建议作为入门投入。**

## 趋势观察

1. **国产 VLA 开始写「消费级单卡」的官方文档。** Wall-X 8 月 31 日直接在仓库里加了一个 `rtx5090/` 目录：装环境、起服务、健康检查、实测笔记。一年前国产具身大模型的开源姿态是「放权重 + 发论文」，现在是「给你一台单卡机器的完整部署脚本 + 一份写到动作维度的任务配方」。**这个变化比模型分数更值得注意** —— 它意味着「个人复现」被当成了正式的支持场景，而不是社区自己想办法。

2. **「LLM 调度既有技能」正在成为 VLA 之外的第二条路。** quackd 这类项目不训练动作，只做任务分解和闭环监督，把机器人已有的 skill 当工具来调（甚至直接走 MCP）。对个人的意义很实在：**不需要数据、不需要显卡、不需要本体，当天就能有能演示的东西**；代价是能力天花板被机器人已有的技能集锁住。两条路不冲突 —— VLA 负责把技能做出来，这一层负责把技能编排起来，个人从哪头切都行。

3. **数据质量工具化了，评价标准跟着变。** 昨天判断「瓶颈从算力移到数据」，今天就出现了专门查数据的 SDK（HFlow）和成体系的数据集采集 / 审计 / 发布工具链（Loop-Engineering-for-VLA）。判断标准也该跟着改：以前问「你有多少 episode」，现在该问**「你有多少 episode 通过了 QC」**。对个人尤其重要 —— 50 组干净数据打得过 200 组脏数据，但前提是你能**证明**它干净。

4. **参与入口（本期核对结果）。**
   - ✅ **[RoboChallenge 真机远程评测](https://robochallenge.ai/)** —— **本期唯一无条件对个人开放的入口**。持续开放型，不需要硬件、不需要机构身份、不需要报名，交模型拿真机分数。
   - ⚠️ **[iCAN「金视线杯」具身智能应用设计挑战赛](https://xingxiancn.com/article/40644)** —— 报名截止 **2026-09-24**（全国初赛 11 月、总决赛 12 月，官网 [g-ican.com](https://www.g-ican.com)），时间上确实还开着，**但要求「经学校推荐、由院校统一组队报名」，且单个院校每组别最多晋级 2 支团队** —— 不满足本栏目「不需要机构身份」的口径。**在校学生可参与，社会个人不行**，列在这里备查。
   - ❌ 已核实关闭的：**GOSIM Paris 2026 Robotics Hackathon**（页面显示 "GOSIM Paris 2026 Has Concluded"）｜第二届无人系统具身智能算法挑战赛（报名 7 月 15 日截止）｜美团低空经济与具身智能挑战赛（9 月 1 日截止，且限高校在校学生）｜亦智杯·亦庄具身智能开发者挑战赛（已从 500 人线上预选收到 43 支团队进线下决赛）。
   - 结论：**比赛类入口对社会个人依然稀缺，绝大多数国内赛事绑定在校学生身份。** 相比之下 RoboChallenge 这种「持续开放的远程真机评测」才是个人真正能反复使用的入口，本栏目后续会持续跟踪这一类，而不是追赛事公告。
